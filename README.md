# Guia Web de Arquitetura de Software — SENAI EAD

Projeto acadêmico desenvolvido com HTML, CSS e JavaScript, com página inicial e três páginas temáticas.

## Conteúdo
- `index.html`: página inicial e navegação para os três conceitos.
- `microsservicos.html`: microsserviços.
- `micro-frontends.html`: Micro Frontends.
- `camadas.html`: Presentation Domain Data Layering.
- `assets/style.css`: identidade visual responsiva.
- `assets/script.js`: alternância de idioma para os textos marcados com `data-pt` e `data-en`.

## Uso de IA (declarado conforme a atividade)
Foi utilizada inteligência artificial generativa (ChatGPT) como apoio à estruturação inicial do site, à elaboração de textos-resumo, à organização dos impactos em prazo, custo, equipe e riscos, e à criação do código HTML, CSS e JavaScript. A equipe deve revisar, corrigir e validar o conteúdo com os artigos originais de Martin Fowler antes da entrega, assumindo a responsabilidade pela versão final.
